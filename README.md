# Pop Chain

## Short description

Hit targets quickly and build the longest chain.

## Description

Pop Chain is a fast, focused, multilingual target-chaining mini-game delivered as a browser extension. Players react to appearing targets, maintain chains, improve their score, and adjust sound and motion preferences.

## Purpose

The extension provides a compact reaction and accuracy challenge for short breaks, with instant access from the browser toolbar and no separate website required.
